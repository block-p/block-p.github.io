# پرتفولیو و رزومهٔ دوزبانه

برای به‌روزرسانی رزومه، در گیت‌هاب فایل `resume.json` را ویرایش کن. ایمیل و نشانی گیت‌هاب مشترک‌اند. متن‌هایی که ترجمه دارند با کلیدهای `fa` و `en` مشخص شده‌اند. برای پروژهٔ جدید، یک ورودی به آرایهٔ `projects` اضافه کن و عنوان، تاریخ و توضیح هر دو زبان را بنویس. فیلد `url` برای پروژه اختیاری است. در متن فارسی، عبارت لاتین داخل `[[...]]` از چپ به راست نمایش داده می‌شود.

وقتی تغییر به شاخهٔ `main` برسد، GitHub Actions دو PDF را می‌سازد و همراه سایت منتشر می‌کند. اگر ساخت هر کدام خطا بدهد، آن اجرا هیچ نسخه‌ای منتشر نمی‌کند. در Pull Request فقط مرحلهٔ ساخت اجرا می‌شود. برای دریافت پیش‌نمایش، فایل `github-pages` را از بخش Artifacts همان اجرا در تب Actions دانلود کن.

## راه‌اندازی روی گیت‌هاب

1. محتویات بسته، از جمله پوشهٔ مخفی `.github`، را در ریشهٔ مخزن روی شاخهٔ `main` قرار بده. هر دو PDF پس از انتشار در دسترس بازدیدکنندگان سایت خواهند بود. شمارهٔ تلفن نسخهٔ انگلیسی از فیلد `phone_en` می‌آید و می‌توانی آن را خالی کنی.
2. در `Settings → Pages → Build and deployment → Source` گزینهٔ `GitHub Actions` را انتخاب کن.
3. در تب Actions، گردش‌کار **Build resumes and deploy portfolio** را روی `main` اجرا کن. دفعات بعد ثبت تغییر روی `main` انتشار را آغاز می‌کند.

ساخت محلی به Python 3.9 یا جدیدتر، pdfLaTeX، XeLaTeX و بستهٔ xepersian نیاز دارد. از ریشهٔ پروژه `python3 build.py` را اجرا کن. خروجی در `dist/` قرار می‌گیرد. فونت Vazirmatn با مجوز OFL در پوشهٔ `fonts` قرار دارد.

این گردش‌کار PDFها را از فایل داده می‌سازد. متن و اطلاعات تماس روی خود صفحه از `site/index.html` می‌آیند.
